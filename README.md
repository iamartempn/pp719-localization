# pp719-localization

Анализ реестра промышленной продукции по ПП 719. Скоринг производителей, покрытие категорий ОКПД2, Streamlit-дашборд.

## Что такое ПП 719

Постановление Правительства РФ N 719 подтверждает происхождение промышленной продукции. Реестр содержит сведения о производителях и баллах локализации. Каждая запись соответствует конкретной продуктовой позиции конкретного производителя и включает итоговый балл локализации, классификаторы ОКПД2 и ТН ВЭД, сроки действия реестровой записи и реквизиты заключения уполномоченного департамента.

## Методология скоринга

Составной показатель производителя рассчитывается по формуле:

```
composite_score = ср_баллы_norm * 0.4 + позиций_norm * 0.3 + охват_норм * 0.3
```

- **ср_баллы_norm** (вес 0.4) - среднее значение баллов локализации по всем позициям производителя, нормированное делением на максимум по выборке. Основной показатель глубины локализации.
- **позиций_norm** (вес 0.3) - количество позиций в реестре, нормированное min-max к [0, 1]. Отражает масштаб присутствия производителя в реестре.
- **охват_норм** (вес 0.3) - количество уникальных префиксов ОКПД2 (первые 4 символа), нормированное min-max к [0, 1]. Характеризует диверсификацию продуктового портфеля по товарным категориям.

## Запуск

```bash
# 1. Загрузка данных из Excel в DuckDB
# Вариант A: через аргумент CLI
python src/ingest.py --excel-path /path/to/production.xlsx --db-path data/registry.duckdb

# Вариант Б: через переменную окружения (для дашборда)
export EXCEL_PATH=/path/to/production.xlsx
python src/ingest.py --db-path data/registry.duckdb

# 2. Валидация схемы
python src/validate.py

# 3. Аналитика (вывод в консоль)
python src/analyze.py

# 4. Запуск дашборда
streamlit run src/dashboard.py
```

## Дашборд

Дашборд состоит из четырёх вкладок:

- **Реестр** - фильтруемая таблица реестровых записей. Фильтры: префикс ОКПД2 (мультиселект топ-20 категорий), поиск по названию предприятия, диапазон баллов. Отображает позиции с ключевыми полями и суммарное количество записей.

- **Производители** - агрегированная аналитика по производителям. Гистограмма топ-20 по числу позиций, диаграмма рассеяния средних баллов относительно охвата ОКПД2 с размером маркера пропорционально числу позиций.

- **Категории ОКПД2** - анализ товарных категорий. График топ-30 категорий по количеству позиций, сводная таблица категорий с средними баллами.

- **Скоринг** - рейтинг производителей по составному показателю. Таблица топ-50 с рангом и всеми компонентами скора, гистограмма composite_score для топ-20.
